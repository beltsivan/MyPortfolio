A modern and responsive skincare business website designed to showcase services
and streamline online appointment booking. The platform provides customers with
an intuitive interface to browse treatments, book appointments, and explore the
business, while giving administrators a comprehensive CMS dashboard to manage
bookings, services, and website content.

### Key Features

- Responsive landing page with modern UI/UX
- Online service booking and appointment scheduling
- User authentication and account management
- Admin CMS dashboard for managing services, bookings, users, and website content
- Real-time data management with Firebase
- Mobile-friendly design with optimized performance
