A native Android mobile application built with Kotlin in Android Studio that mirrors the McDelivery Philippines mobile app experience. Features include menu browsing, cart management, order placement, and real-time order status tracking. The backend uses Firebase (Authentication, Firestore, Cloud Messaging) for user management, real-time data sync, and push notifications.
