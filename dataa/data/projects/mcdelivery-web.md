A full-stack web application that replicates the core functionality of the McDelivery Philippines platform. Features include user authentication, menu catalog with categories, cart management, order placement, and admin dashboard for order tracking. The backend is powered by PHP with a MySQL database managed through phpMyAdmin, handling user data, menu items, and order records.
